# 调研字段清单与信源

按体系分别检索，**搜完再写**。每个字段后标了优先级：
- **必查**：没有就不能成稿
- **应查**：有就写，没有写「未公开」
- **选查**：有余力再补

## A. 体系级（每根柱子都要）

| 字段 | 优先级 | 怎么搜 / 信源 |
|---|---|---|
| 全称与加挂牌子 | 必查 | 官网「集团简介」、百度百科 |
| 主管单位与性质 | 必查 | 官网、省委/市委宣传部机构编制表述。「省委直属事业单位，省委宣传部管理」「省属国有文化传媒企业」这类原文表述直接用 |
| 成立/合并时间、历史渊源 | 应查 | 官网、百科 |
| 现任主要领导（书记/董事长/社长/台长/总编辑） | 必查 | 官网领导之窗、近一年官方通稿。**注意职务变动，核对最新报道日期** |
| 控股上市公司/发债主体 | 应查 | 企查查、上交所/深交所公告、债券募集说明书 |
| 旗下主要资产（频道、频率、报纸、客户端、网站） | 必查 | 官网组织架构页 |
| 新媒体账号矩阵与粉丝量 | 应查 | 客户端下载量（应用商店）、微博/抖音/视频号粉丝数 |

## B. 单家媒体（报纸 / 客户端 / 频道）

| 字段 | 优先级 | 怎么搜 / 信源 |
|---|---|---|
| 定位 | 必查 | 官网、百科；创刊年份、历史沿革 |
| 用户/发行量级 | 应查 | 官网、年度报告、行业榜单 |
| 近年战绩（近 2–3 年代表作） | 必查 | 搜「媒体名 + 阅读量/亿」「媒体名 + 首发」「媒体名 + 转发」；看它自己的年度回顾稿 |
| 内容侧重点 | 必查 | 从它的栏目设置和近期首页归纳，用自己的话写 3–5 个关键词 |
| 行业奖项 | 应查 | 中国新闻奖公示名单（中国记协官网/search「第XX届中国新闻奖 + 媒体名」）、省新闻奖 |
| 报道链接 | 应查 | 找到代表作原文链接，贴在「报道链接：」后 |
| 经营与技术（含 AI 动作） | 必查 | 搜「媒体名 + AI」「媒体名 + 战略合作」「媒体名 + 签约」「媒体名 + 大模型/数字人/AIGC」；看它跟字节、阿里、腾讯、百度谁签了 |
| 分发渠道结构 | 应查 | 看它内容发在哪些平台、各平台数据表现（视频号是不是空白位，这个对腾讯很关键） |
| 历史处罚 / 负面 | 应查 | 搜「媒体名 + 处罚/警告/敲诈/通报」；国家新闻出版署处罚公告 |
| 社会责任报告 / 自述不足 | 选查 | 官网「社会责任报告」年度后记，摘它自己承认的短板 |

## C. 经营与风险（上市/发债主体必做）

搜索路径：`公司名/股票代码 + 2025年报 / 2026一季报 / 亏损 / 诉讼 / 监管工作函 / 巡视整改 / 债券`。

要抓的：
- 营业总收入、净利润、净资产 三年走势（至少三个年度 + 最新一期）
- 亏损主因（通常指向控股子公司）
- 未结诉讼数量与涉案金额、重大调解/判决
- 交易所监管工作函、证监会问询
- 省委巡视整改通报原文表述
- 关停并转动作（关了几个频道/频率/账号）
- 一把手公开讲话里的关键词（用来推「交流建议」）
- 债券触发机制、账户冻结、退市风险警示

## D. 腾讯相关（每篇必须写完）

1. **既有合作基础**：搜 `媒体名/集团名 + 腾讯 + 战略合作`（腾讯云、腾讯文旅、腾讯互娱、腾讯新闻、微信支付、腾讯公益都算）；带签约时间和出席人。
2. **可谈的具体项目**：从下列池子里挑能对应上的，写清「为什么是它」：
   - 腾讯 SSV 繁星计划（文博/中小博物馆数字化，对应有省级文物局合作的广电）
   - 混元 / WorkBuddy（对应已接入第三方大模型、或明确要接大模型的客户端）
   - 腾讯云音视频 AIGC、多语种、微短剧（对应广电/融媒体中心）
   - 视频号创作者扶持 + 流量运营（对应「有号无数据」的账号）
   - 数字人（对应记者个人 IP 化、种子基金）
   - 腾讯公益 / 99 公益日（对应有公益矩阵、能实际募款的都市报）
   - 微信生态 / 小程序 / 支付（对应接入政务服务平台的客户端）
   - 腾讯新闻内容合作（对应原创调查能力强的媒体）
3. **竞对占位**：明确写它跟字节/阿里绑到什么程度（剪映+火山引擎+抖音分发 = 深度绑定），腾讯还剩哪些口子。

## 核实纪律

- 领导职务以**最近一年内**的官方通稿为准；变更过的写「（YYYY 年 M 月由 X 变更而来）」。
- 各百科站（百度/搜狗/快懂）与黄页站的「现任领导」栏常年不更新且互相冲突。**同一职务出现两个人名时**，以近一年官方通稿或主流媒体报道为准，并在简报里标注任职起始时间（如「总编辑孙伟（2025年起）」）；实在定不了的写「待核实」。
- 一个省不一定有独立的市场化都市报集团（如黑龙江的都市报在省报集团内）。找不到第四根柱子时，改用**省会城市广电**补位，不要硬套模板。
- 财务数字只取定期报告/公告原文，注明报告期。
- 奖项等级只取中国记协公示名单。
- 搜不到的字段，在正文对应位置写「待核实」，并在回复的待核实清单里列出来。
- 每篇简报的「待核实」项不要超过 8 条，超过说明调研没做透。
