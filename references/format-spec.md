# 版式与写作规范（源自《陕西媒体情况简报》定版）

## 一、Word 版式参数（脚本已内置，勿改）

| 元素 | 字体 | 字号 | 其他 |
|---|---|---|---|
| 标题1（文首大标题） | 黑体 | 22pt（44半点） | 居中，段前 8.4pt / 段后 13.2pt，行距 1.43 |
| 标题2（一、二、三…） | 黑体 | 14pt（28半点） | 段前 13.2pt，左对齐 |
| 标题3（（一）（二）…） | 黑体 | 12pt（24半点） | 段前 8.4pt，左对齐 |
| 正文 | 宋体 | 11pt（22半点） | 行距 1.15，段后 10pt，首行无缩进 |
| 表格 | 宋体 | 11pt | Table Grid 全边框，首行加粗，表宽 100% |
| 页脚 | 宋体 | 9pt | 居中页码 |

纸张 A4，常规页边距。

## 二、markdown 中间稿语法

脚本解析的标记只有这几个，写稿时严格遵守：

| 语法 | 渲染结果 |
|---|---|
| `# 文字` | 标题1（居中大标题，全篇只出现一次） |
| `## 文字` | 标题2 |
| `### 文字` | 标题3 |
| `**文字**` | 加粗（用于段首标签：「**定位：**」「**近年战绩：**」） |
| `==文字==` | **红色加粗**（用于需要现场重点看的句子，全篇控制在 3–5 处） |
| `\| a \| b \|` 连续行 | 表格；第一行自动成为加粗表头 |
| 空行 | 分段 |

- 表格用标准 markdown 管道表格，分隔符行 `|---|---|` 可写可不写。
- 正文段落里不要写 markdown 列表符 `-`，编号就用纯文本 `1. ` `2. `（与陕西稿一致）。
- URL 直接写裸链接，脚本原样排版，不加超链接。
- 不要用 `>` 引用、不要写代码块、不要写图片。

## 三、写作颗粒度（最重要，决定简报好不好用）

**每段话要能直接当谈资用。** 判断标准：删掉这段话里的形容词后还剩几个硬事实？少于 3 个就是废话。

对的标准（摘自陕西稿）：

> 《黄养海卖瓜"简史"》获通讯二等奖——作者张斌峰，全文仅1100多字，是本届获奖通讯中最短的一篇；题材从西安"夏秋瓜果临时销售点"政策切入，以流动商贩黄养海这个"小人物"记"史"，反映城管与商贩关系从"斗争"到"和睦"的变化；配套评论《"瓜果地图"里的民生温度》被《人民日报》等数十家报纸转载、全网点击超150万。

（人名、字数、题材切口、转载量、点击量——5 个硬事实。）

错误示范：「该报近年来深耕民生领域，推出了一批有影响力的报道，社会反响良好。」

### 各字段怎么写

- **定位**：一句话说清「它是谁的、什么性质、多大盘子」。带创刊/成立年份、历史渊源、用户/发行量级。
- **近年战绩**：挑 3–5 条，每条写清「时间 + 作品/事件 + 结果（阅读量、转载、推动了什么）」。有全国性影响的事件优先。
- **行业奖项**：中国新闻奖写清第几届、几件、等级分布；配表格逐件列要点。
- **经营现状**：上市公司或发债主体才写。营收/净利润/净资产三年走势、亏损主因、诉讼、监管函、巡视整改、关停并转动作。非上市的写「未公开财务数据」。
- **经营与技术（含AI）**：它现在用什么 AI、跟谁绑的（字节系 / 阿里系 / 腾讯系）、客户端迭代动作、分发渠道结构。**这条直接决定腾讯怎么谈，必须查实。**
- **风险提示**：聚焦「它的报道会打到谁」。舆论监督强、曾推动官员免职、进过最高检/中央通报的，标为最高优先级，并给出现场话术（「如何让我们第一时间拿到准确信息、如何更快响应」）。
- **交流建议**：从对方公开讲话里摘一句关键词（如「打赢翻身仗」「产业重塑」），推断它想谈什么，写一句。
- **腾讯可谈的切入点**：分两段——
  1. `既有合作基础：` 腾讯与它（或它控股公司）已有的合作，带时间。
  2. `可考虑合作：` 编号列 2–5 条，每条写「腾讯哪个产品/能力 × 它哪个具体需求 × 为什么现在是窗口」。

## 四、篇幅

陕西稿（4 个体系、9 家媒体）约 8 页 / 6000 字。按体系数量等比缩放：
- 1–2 个体系：3–4 页
- 3–4 个体系：6–8 页
- 单城市：3–5 页

宁可短而实，不要长而空。
